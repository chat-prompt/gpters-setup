# GPTers 설치도우미

Claude Code, Codex 같은 AI 도구를 내 컴퓨터에 맞게 설치하고, 로그인과 첫 요청까지 한 화면씩 함께 안내하는 앱이에요.

이 저장소는 설치 파일을 내려받는 곳이에요. 앱의 소스 코드는 공개하지 않아요.

## 내려받기

[최신 버전 내려받기](https://github.com/chat-prompt/gpters-setup/releases/latest)

| 운영체제 | 파일 | 지원 |
|---|---|---|
| Windows | `GPTersSetup-Windows.exe` | Windows 10 버전 1809 이상 |
| Mac | `GPTersSetup-Mac.dmg` | macOS 13 이상 권장 (Apple Silicon·Intel) |

- Windows 설치 파일은 **지니파이 주식회사** 이름으로 서명되어 있어요. 설치 창의 게시자가 이 이름인지 확인하세요.
- Mac 앱은 **Jinwoo Hyun** 개발자 이름으로 서명하고 Apple 공증을 마쳤어요.

## 사용하려면

GPTers 계정으로 로그인해야 해요. 쓰려는 AI 도구의 계정(Claude, ChatGPT 등)은 각 도구 안내에서 따로 로그인해요.

## 파일 확인

각 릴리스의 `SHA256SUMS.txt`에 설치 파일의 SHA-256 값이 있어요.
